# Portfolio technique — Sacha Vinches

Administrateur Systèmes et Réseaux en formation (TSSR), ce dépôt regroupe une sélection de travaux pratiques réalisés en formation (ADRAR Pôle Numérique) : infrastructures virtualisées, Active Directory, réseaux Cisco, serveurs Linux.

## Compétences couvertes

| Domaine | Technologies |
|---|---|
| Virtualisation | Hyper-V, VMs Windows Server / Debian |
| Réseaux | VLAN (802.1Q), routage inter-VLAN (ROAS), NAT/PAT, ACL, pfSense, Cisco IOS |
| Annuaire | Active Directory, migration de schéma, réplication multi-maître, DFS-R, méthode AGDLP |
| Systèmes | Debian, Windows Server, Samba, Apache2, Bind9 (DNS), IIS, DHCP |
| Sécurité | Tunnel IPSEC site-à-site, SSH, segmentation réseau |
| Scripting | Bash (sauvegardes automatisées, cron), batch Windows |

## Projets

1. [Infrastructure virtualisée VLAN / pfSense / DHCP / DNS / WiFi](projects/01-infra-vlan-pfsense-dhcp-dns-wifi) — projet le plus complet : conception et déploiement d'une infra multi-VLAN avec pare-feu pfSense, supervision SSH et point d'accès WiFi géré
2. [Migration Active Directory & haute disponibilité](projects/02-migration-ad-2012-2019-replication-dfs) — migration Windows Server 2012 → 2019, réplication AD multi-maître, réplication DFS-R
3. [Étude de cas VLAN / NAT (Cisco)](projects/03-vlan-nat-cisco-etude-cas) — conception d'architecture réseau segmentée pour une PME en croissance
4. [Serveurs Linux Debian (Samba, DNS, Web, IPSEC)](projects/04-serveur-linux-debian-samba-dns-web-vpn) — TP infrastructure Linux avec tunnel VPN site-à-site
5. [Adressage IP et sous-réseaux](projects/05-adressage-ip-subnetting) — exercices de calcul et segmentation IP
6. [Infrastructure Hyper-V : DHCP / DNS / IIS](projects/06-hyperv-dhcp-dns-iis) — déploiement de services Windows Server sous hyperviseur
